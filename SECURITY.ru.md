## Поддерживаемые версии

Исправления безопасности выпускаются только для последней опубликованной версии `wydocmost`. Старые версии не поддерживаются; перед сообщением о проблеме безопасности обновитесь до последнего выпуска.

Для CLI требуется Node.js 20 или новее. CLI подключается к экземпляру Docmost через его HTTP API. Совместимость может различаться в зависимости от версии Docmost; укажите в сообщении версию Docmost и сведения о развертывании, но не включайте учетные данные или токены сеанса.

## Локальные учетные данные

Команда `wydocmost login` предлагает системную связку ключей или JSON-файл для хранения токена сеанса Docmost. По умолчанию выбирается связка ключей. Если системное хранилище учетных данных не может сохранить токен, CLI выдаст предупреждение и переключится на JSON. JSON-файл называется `credentials.json` и находится в настроенном каталоге учетных данных. Путь по умолчанию — `~/.config/wydocmost/credentials.json`; для выбора другого места можно использовать `XDG_CONFIG_HOME`, `--config-dir` или `WYDOCMOST_CONFIG_DIR`. В поддерживаемых операционных системах CLI запрашивает права `0600` для файла и создает новый каталог учетных данных с правами `0700`. При использовании связки ключей JSON-файл содержит только метаданные для поиска записи в связке ключей, но не токен. Храните каталог учетных данных в тайне, особенно если выбран пользовательский путь. Пароль не сохраняется.

Если токен мог быть раскрыт, отзовите сеанс в Docmost, если такая возможность доступна, удалите локальный файл учетных данных и запустите `wydocmost login`, чтобы сохранить новый сеанс.

Не добавляйте в коммиты `credentials.json`, файлы окружения и другие секреты. Репозиторий игнорирует распространенные имена файлов учетных данных и окружения. npm-пакет содержит README, лицензию, документы политики безопасности, манифест пакета и скомпилированные файлы CLI; локальные учетные данные в него не входят.

## Защита персональных данных в Индонезии (UU PDP)

Закон Индонезии о защите персональных данных, **Закон № 27 от 2022 года (UU PDP)**, действует. См. [официальную запись о нормативном акте](https://peraturan.go.id/id/uu-no-27-tahun-2022) или [официальный текст закона](https://peraturan.bpk.go.id/Details/229798/uu-no-27-tahun-2022).

`wydocmost` хранит учетные данные сеанса Docmost локально и отправляет аутентифицированные запросы в выбранный пользователем экземпляр Docmost. Держите каталог учетных данных в тайне и не передавайте токены сеанса. Организациям и частным лицам, использующим CLI, следует самостоятельно оценить свои действия по обработке данных и обязанности по UU PDP и другим применимым правилам. Это примечание приведено только для справки и не утверждает, что конкретное развертывание или использование CLI соответствует законодательству.
